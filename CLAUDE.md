# «Волжский Горизонт» — как работать с этим репозиторием

Проект круизного судна 139 × 16,5 м под конкурсное задание УЖЦ ОСК 2026.
Модель живёт в Blender, все числа — в параметрических библиотеках
`src/lib/`, вся графика и все документы собираются скриптами из
`scripts/`. Руками в репозитории не набирается почти ничего: если число
встречается в записке, оно посчитано.

Подробности проекта — в [README.md](README.md). Здесь только то, что нужно
знать, чтобы начать работать и ничего не сломать.

## Первое, что надо проверить

1. **Blender должен быть запущен** с открытым `blender/gorizont.blend` и
   включённым MCP-аддоном (порт 9876). Без него доступны только расчёты и
   2D-документы, но не модель и не рендеры.
   Бинарник: `E:\SteamLibrary\steamapps\common\Blender\blender.exe`.
2. **Фоновый Blender на этой машине виснет.** `blender -b` не доходит даже
   до запуска Python — проверено с `--factory-startup` и без файла. Рендеры
   идут через открытую сессию по MCP; окно на это время показывает «не
   отвечает», это нормально. В `scripts/рендер_всего.py` написано
   «запускать только фоновым процессом» — сейчас этот путь не работает.
3. **Вызов MCP отваливается по таймауту ≈60 с, а работа продолжается.**
   Запустил рендер — не перезапускай, а жди появления файлов.

## Где что лежит

```
src/lib/          параметрические библиотеки: все числа проекта
scripts/          генераторы: модель, рендеры, чертежи, документы
blender/          gorizont.blend — единственный файл модели
renders/горизонт_2026/   виды, интерьеры, планы, схемы, чертежи
CAD/              DXF, OBJ и STL для AutoCAD и ANSYS
docs/проект/      записка и сверка с описанием — пишутся руками
docs/расчёты/     теория корабля — генерируется скриптом
```

Скрипты с префиксом `blender_` работают внутри Blender по MCP, остальные —
обычный python из корня репозитория.

## Проверки: запускать до и после правок

```bash
python scripts/сверка_документов.py     # числа в документах против модели
python scripts/спецификация_фундамента.py
python scripts/карты_техпроцесса.py
```

В Blender по MCP:

```python
import blender_аудит as A
A.pairs()        # пересечения деталей
A.support()      # предметы, которые ни на чём не стоят
A.stilts()       # кресла на ходулях вместо помоста
A.seating()      # стулья, повёрнутые от стола
A.enclosure()    # дыры в ограждении помещений
A.seats()        # счёт посадочных мест, пишет gorizont_seats.json
```

Что каждая ловит и почему появилась — в
[docs/проверки_модели.md](docs/проверки_модели.md). Норма на сейчас:
пересечений 0, висящих 0, ходуль 0, отвёрнутых стульев 0, дыр в ограждении
18 точек по одному-два луча из 72 (волосяные стыки, не проёмы).

## Правило проекта: число живёт в одном месте

Поменял толщину настила — поехали масса, осадка, остойчивость и все
нагрузки, потому что `gorizont_hydro` берёт массу корпуса из
`gorizont_struct.steel_weight()`, а не из константы. Так же устроено всё
остальное:

- посадка в залах → `blender_аудит.seats()` → `src/lib/gorizont_seats.json`
  → планы палуб;
- техпроцесс → `gorizont_tp` → маршрутная и операционная карты;
- успокоительные цистерны → `gorizont_roll` → нагрузка масс в
  `gorizont_hydro.groups()`.

Если правишь число руками в записке — почти наверняка ошибка. Правь
библиотеку и перегенерируй.

## Порядок пересборки после правки модели

```python
# в Blender
import blender_мебель as M;  M.rebuild()

import bpy; bpy.ops.wm.save_mainfile()
import blender_рендер_планов as P;      P.render_plans(); P.render_section()
import blender_рендер_интерьеров as I;  I.render_rooms()
import blender_рендер_видов as V;       V.render_views()
import blender_рендер_схем as S;        S.render_schemes()
```


Интерьеры считаются около четырёх минут на кадр, семь кадров — полчаса.
Виды — полторы минуты на кадр.

## Язык и стиль

Всё по-русски: имена файлов, переменные предметной области, комментарии,
сообщения. Комментарий объясняет, **почему** так сделано, а не что делает
строка. Если код обходит грабли — назови грабли: «момент свободной
поверхности считается как для обычной цистерны: переносный член A·y² сюда
не входит, переток жидкости и есть действие успокоителя».

- **эксплуатация на глубине до 1,5 м** — нынешний корпус на 1,5 м вытесняет
  2548 т при полной массе 4073 т, дефицит 1525 т (37 %). Не лечится диетой:
  предел для габарита шлюза на 1,5 м — около 3100 т даже у понтона. Меняются
  обводы, длина, движители (винт ⌀1,70 м при такой осадке не заглубляется —
  предел ⌀0,77 м) и общее расположение;
- **перевозка не менее 4 личных автомобилей** — нужен гараж 110…130 м²,
  аппарель и помещение для транспорта по требованиям РРР;
- **не менее 5 % пассажиров группы мобильности М4** — 11 мест на
  кресле-коляске против нынешних 8 доступных кают, плюс эвакуация;
- **гибридная ЭУ на СПГ/метаноле/водороде переехала в минимальные
  требования** — перестала быть опцией. Решение: СПГ, танки типа C на палубе;
  метанол отпал окончательно (543 т против 254 т при дефиците массы);
- **всесезонная эксплуатация маршрута** — сейчас навигация 180 суток.
