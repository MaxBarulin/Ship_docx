# «Волжский Горизонт» — модель круизного судна

Проект под конкурсное задание УЖЦ ОСК 2026: круизное судно для рек и озёр
России, не менее 200 пассажиров, автономность от 10 суток, перевозка
маломобильных пассажиров.

Судно построено по описанию Алексея; все расхождения с этим описанием
разобраны построчно в [`docs/проект/сверка_с_описанием.md`](docs/проект/сверка_с_описанием.md),
а решения и их причины — в [`docs/проект/записка_горизонт.md`](docs/проект/записка_горизонт.md).

Ранняя ветка работы — параметрическая модель проекта 141 на build123d —
из рабочего дерева убрана: судно пересобрано с нуля в Blender по новому
описанию. Всё, что было по 141, лежит в истории до коммита, который убрал
эти файлы; при необходимости достаётся оттуда.

## Три решения, определившие компоновку

**Четвёртый закрытый ярус.** Перечень помещений из описания в три палубы не
влезает: не хватало 138 м фронта борта на первой палубе, 110 м на второй и
74 м на третьей, и сверх того не были учтены ~204 м² коридоров и центральный
блок шириной 4.9 м (~360 м² на палубу). Ярус 9.80…12.60 добавляется бесплатно
в габарит: его крыша в 9.8 м над водой при лимите 13.2 м.

**Шлюпки внутри габаритной ширины.** Судно ходит через шлюзы, за борт не
должно выступать ничего. По бортам шлюпочной палубы сделаны спонсоны до
полушироты 8.15 м — на 0.10 м внутри обвода корпуса; шлюпки стоят на них, на
кильблоках. Между шлюпками и надстройкой проходит сквозной **шлюпочный
променад 1.30 м** по обоим бортам на всю длину яруса, не менее двух дверей на
борт из каждого закрытого блока.

**Доступность внутри категорий.** Отдельной «каюты для инвалида» нет
сознательно: пассажир должен выбирать класс и платить за класс. Поэтому
доступные каюты — исполнения существующих категорий: 4 бизнес, 2 люкс,
2 стандарт. Числа эргономики заданы в `src/lib/gorizont.py` и проверены на
модели: проезд 0.90, круг разворота 1.50, проём 0.90, порогов нет, койка
0.48, подход к койке 1.20, душ без поддона, поручни 0.85.

## Теория корабля и прочность

Расчёты лежат в [`docs/расчёты/теория_корабля.md`](docs/расчёты/теория_корабля.md)
и считаются кодом из `src/lib/gorizont_hydro.py`, `gorizont_struct.py`,
`gorizont_strength.py` по той же таблице шпангоутов, по которой построена
модель. Методика — курс теории корабля и строительной механики СПбГМТУ:
элементы теоретического чертежа численным интегрированием, пантокарены
отсечением сечений наклонной ватерлинией, изгибающий момент из строевых
нагрузки и сил поддержания на тихой воде и на волне класса «О».

| Что проверяли | Результат | Вывод |
|---|---|---|
| Посадка | T = 2.06 м, дифферент +0.045 м | ровный киль; проектные 2.8 м потребовали бы 1516 т балласта — отказались |
| Начальная остойчивость | h = 8.12 м, период качки 4.6 с | с большим избытком, качка резкая |
| Остойчивость на больших углах | K = 13.6 (корпус) и 18.8 (с надстройкой) при норме ≥ 1 | все нормы РРР класса «О» выполнены |
| Непотопляемость | одноотсечная, худший случай T = 2.64 м | надводный борт остаётся 1.56 м |
| Ходкость 22 км/ч | 1244 кВт из установленных 1800 | обеспечена при глубине фарватера от 8 м |
| Ходкость 26 км/ч | требуется 2363 кВт | **не обеспечена**, нужны колонки 2 × 1300 кВт |
| Продольная прочность | 152.6 МПа из допускаемых 195 | обеспечена, запас 1.28 |
| Кница спонсона ВГ-2026.15.01 | 100.8 МПа из 211 | обеспечена, запас 2.1 |

Три вывода, которые меняют проект:

1. **Судно всплывает на 2.06 м вместо 2.8.** Это хорошо для маршрутов
   (мелководные участки становятся доступны) и плохо для комфорта: малая
   осадка задирает метацентрический радиус, остойчивость избыточная,
   качка резкая. Лечится скуловыми килями, успокоителем качки (он и так
   требуется по заданию) и снижением высоты борта до 3.5 м в следующей
   итерации — заодно минус 150 т стали.
2. **26 км/ч с колонками 2 × 900 кВт не выйдет.** Максимум 24.3 км/ч.
   Электростанция 4 × 1200 кВт позволяет поставить 2 × 1300 кВт без
   изменений — тогда 26.6 км/ч.
3. **22 км/ч держатся при глубине фарватера от 8 м.** На четырёхметровом
   мелководье предел не по мощности, а по близости к критической
   скорости — не более 16 км/ч. Это в расписание.

### Конструкция корпуса

Смешанная система набора: продольная в днище, втором дне и главной палубе,
поперечная по бортам. Шпация 550 мм, рамная 2200 мм, восемь
водонепроницаемых переборок, двойное дно 1.30 м с понижением до 0.47 м в
машинном отделении. Материал основных связей — 09Г2С ГОСТ 19281.

Набор построен в модели (коллекция `40_Набор_корпуса`, 92 тыс. полигонов,
ноль пересечений с остальной моделью), из тех же размеров связей считаются
и масса корпусной стали (1096 т), и момент сопротивления эквивалентного
бруса (0.853 м³ по палубе).

## Что сделано

- Модель `blender/gorizont.blend` — 713 объектов: корпус, четыре яруса
  надстройки с оконными поясами и остеклением, 137 кают, трап-холлы с
  лифтами, все общественные и служебные помещения с мебелью, машинное
  отделение, спасательные средства, леера, мачта, солнечные батареи.
- Экспорт `GLB/gorizont.glb` (8.4 МБ) для просмотра и презентации.
- Расчётная часть: `src/lib/gorizont.py` (размерения, каюты, эргономика
  доступности, таблица шпангоутов) и `src/lib/gorizont_ga.py` (общее
  расположение как построено, функции `summary()` и `compare()`).
- Графика в `renders/горизонт_2026/`: 8 внешних видов, 6 планов палуб с
  подписями и масштабной линейкой, 9 планов кают по категориям, 4 интерьера
  общественных помещений, продольный и два поперечных разреза, взрыв-модель
  (ортогональная и 3D), схема доступности и путей эвакуации, схема судовых
  систем, сводный лист проекта.
- Документы: сверка с описанием и пояснительная записка в `docs/проект/`.

### Как проверялась модель

Инструменты аудита живут в `bpy.app.driver_namespace` открытой сцены:

| Проверка | Результат |
|---|---|
| `audit_collisions` — попарные пересечения | **0** на всех 713 объектах |
| `audit_outside_hull` — выход за обвод корпуса и надстройки | **0** |
| `audit_watertight` — замкнутость оболочек | незамкнуты 2 объекта из 713 |

Незамкнуты `корпус` (84 кромки — вырезы трап-холлов в настиле главной палубы)
и `настил_первой_палубы` (вырез над машинным отделением). Оба выреза закрыты
комингсами; замкнуть их можно только смоделировав внутренности шахт.

Каждый шаг сборки снимался минимум с трёх сторон и, где нужно, поперечным
разрезом. Аудит по ходу работы поймал и заставил исправить: 10 кают экипажа в
носу первой палубы (до 0.49 м за борт), 27 кают в надстройке, Z-конфликт
оконных поясов с остеклением по всей длине, каюты, утопающие в настиле на
2 см, зубчатую ватерлинию и несимметричный носовой блок 4-го яруса.

## Что осталось

- **Ходкость, остойчивость, посадка, прочность не считались.** Набор корпуса
  не смоделирован, корпус — односкинная оболочка.
- **Экипаж: 57 мест из заявленных 85.** Соотношение 212 / 57 = 1 : 3.7,
  у Viking Longship — примерно 190 / 50. Сокращать сервис или искать место —
  решение команды, а не модели.
- **Ресторан 168 мест на 212 пассажиров** — одна посадка не закрывается,
  нужны две смены либо добор мест в баре.
- Общественная программа ужата на 6…17 % против описания; построчно в сверке.
- Носовой панорамный салон на главной палубе вышел 39 м² — обвод в носу
  сужается быстрее, чем хотелось.
- Интерьеры кают собраны из простых объёмов: планы кают читаются, но
  фотореалистичных видов изнутри по ним не сделать без доработки мебели.
- Инструментарий text-to-cad (`scripts/setup-cad.sh`, `scripts/ensure_chromium.py`,
  `requirements-cad.txt`, скиллы в `.agents/` и `.claude/`) оставлен, но сейчас
  ничем не используется: «Горизонт» собирается в Blender.

## Как пересчитать числа

```bash
python -c "import sys; sys.path.insert(0,'src'); from lib import gorizont_ga as ga; print(ga.summary())"
python -c "import sys; sys.path.insert(0,'src'); from lib import gorizont_ga as ga; [print(r) for r in ga.compare()]"
```

`summary()` даёт каюты, места, экипаж и вместимость шлюпок; `compare()` —
таблицу «по описанию / в модели / разница» по площадям помещений.

```bash
python -c "import sys;sys.path.insert(0,'src');from lib import gorizont_hydro as H;e=H.equilibrium();print('T=%.3f  h=%.3f'%(e['T'],H.initial_stability()['h']))"
python -c "import sys;sys.path.insert(0,'src');from lib import gorizont_strength as S;[print(r['condition'],round(r['sigma_deck'],1)) for r in S.stresses()['rows']]"
python scripts/расчёты_графики.py      # кривые, ДСО, прочность, ходкость
python scripts/теоретический_чертёж.py # теоретический чертёж
python scripts/корпус_и_ординаты.py    # корпус и таблица плазовых ординат
python scripts/чертёж_мидель.py        # конструктивный мидель-шпангоут
python scripts/чертёж_набора.py        # схема набора корпуса
python scripts/чертёж_кницы.py         # чертёж детали и DXF
```
