# «Волжский Горизонт» — колёсное круизное судно мелкой осадки

Проект под конкурсное задание УЖЦ ОСК 2026, редакция 2. Прототип по
технике — ПКС-180 «Золотое кольцо» (колёса в нишах, две жилые палубы);
внешность своя, современная: чёрный корпус, светлая лента главной палубы,
красная линия, графитовый ярус кают.

Все числа проекта живут в параметрических библиотеках `src/lib/`, вся
графика и документы собираются скриптами из `scripts/`. Если число
встречается в записке или на плане — оно посчитано, не набрано.

- **Что за судно и почему оно такое** — [`docs/проект/концепция.md`](docs/проект/концепция.md)
- **Что сделано и что впереди** — [`docs/сводка_состояние.md`](docs/сводка_состояние.md) (генерируется)
- **Как работать с репозиторием** — [`CLAUDE.md`](CLAUDE.md)

## Что определило проект

**Две жилые палубы.** Под главной палубой 2,1 м — только цистерны и
механизмы. Выше солнечной палубы — 0,9 м до габарита по мостам. Как у
прототипа.

**Колёса на миделе, над ними атриум.** Потеря плавучести в нишах даёт
просадку без дифферента, корма свободна под аппарель, а работающее
колесо видно из атриума через витражи кожухов. Ниши — от киля до палубы,
с обтекаемыми торцами.

**Метанол.** Танк СПГ типа C не встаёт ни в трюм, ни под габарит на
солнечной палубе. Метанол — в цистернах второго дна с коффердамами.

**Фасад из компоновки.** Тип поверхности борта задаёт то, что за ней:
общественные помещения — панели остекления, каюты — ряд окон, гараж —
жалюзи. Передвинул ресторан — уехала панель.

## Где что лежит

```

scripts/                 генераторы: модель, планы, схемы, сверки
docs/задание/            КЗ ред. 2 и матрица оценки — не менять
docs/план/               план и Гант команды
docs/проект/             концепция, записка, разбор перехода на ПКС-180

```
