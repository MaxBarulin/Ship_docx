## 1. Критический путь

Всё остальное — параллельно и раньше. Задержка любого звена сдвигает защиту.

```
КЗ → концепт изделия → выбор детали/узла → чертёж детали → 3D модель
   → техпроцесс → трудоёмкость → анализ мощностей → планировка участка
   → численность персонала → затраты → себестоимость → цена
   → финмодель (NPV/IRR/окупаемость) → выводы → презентация
```

Три правила, удерживающие путь:

1. **Выбор детали/узла — не позже T+20%.** После этого конструктив не меняется. Сложность детали (r178, 2.0 балла) выбирается один раз и осознанно.
2. **Финмодель Лены заполняется волнами, а не в конце.** Шаблон с плейсхолдерами готов до старта; черновые цифры на T+40%, уточнение на T+60%, заморозка на T+72%.
3. **Инженерная заморозка на T+72%.** После неё правки только в текст, презентацию и оформление.

## 5. Правила, которые дают баллы дешевле всего

1. **Каждый расчёт — с обоснованием и ссылкой на источник.** По формулировкам таблицы разница между «рассчитано» и «рассчитано с подтверждением» — регулярно 1 балл.
2. **Сравнительный анализ там, где он требуется.** Материалы без сравнения с заменителями — минус 0.5 (r32). Аналоги изделия — минус 0.5 (r98).
3. **Детализация вместо укрупнения.** По затратам «укрупнённый расчёт» = 2, «максимально детализировано с подтверждением» = 3.
4. **Числовая оценка и ранжирование рисков.** Без цифр — минус 0.5, без ранжирования — ещё минус 0.5.
5. **Поведение и рабочее место.** До −1.0 по r25 без всякой связи с содержанием проекта.
6. **Регламент защиты.** 1.0 балл, теряется целиком за превышение.
